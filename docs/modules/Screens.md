# 页面模块文档

## 1. 首页 (Home Screen)

**文件路径**: `client/screens/home/index.tsx`

### 功能说明
- 展示4个高频快捷决策模板（今天吃什么、今天喝什么、谁买单、谁做家务）
- 展示最近创建的自定义决策（最多6个）
- 点击模板/自定义决策进入转盘决策页
- 长按自定义决策可编辑或删除
- 右下角悬浮按钮创建新决策

### 交互逻辑
| 操作 | 行为 |
|------|------|
| 点击模板卡片 | 跳转决策页，传入选项数据 |
| 点击自定义决策卡片 | 跳转决策页 |
| 长按自定义决策卡片 | 弹出编辑/删除菜单 |
| 点击 + 按钮 | 跳转编辑页创建新决策 |
| 点击"查看全部" | 跳转全部页 |

## 2. 全部页 (Explore Screen)

**文件路径**: `client/screens/explore/index.tsx`

### 功能说明
- 按分类展示所有预置模板（饮食、生活日常、休闲娱乐、学习工作、聚会游戏）

## 3. 决策页 (Decision Screen)

**文件路径**: `client/screens/decision/index.tsx`

### 功能说明
- 转盘动画展示选项
- 支持自定义旋转时长
- 点击转盘开始旋转
- 旋转结束后显示结果弹窗
- 支持再来一次、分享、排除、确认操作
- 旋转时播放音效（渐弱）
- 决策完成后发送本地通知

### 路由参数
```typescript
{
  decisionId: string;    // 决策ID
  decisionName: string;  // 决策名称
  options: string;       // JSON序列化的选项数组
  weights?: string;      // JSON序列化的权重数组（可选）
  category?: string;     // 分类名称（可选）
}
```

### 结果弹窗布局
```
┌─────────────────────────────────┐
│  [图标] 决策如上，快去执行吧！   │
│                                 │
│  [再来一次]  [分享]             │
│  [排除]      [确认]             │
└─────────────────────────────────┘
```

## 4. 编辑页 (Edit Screen)

**文件路径**: `client/screens/edit/index.tsx`

### 功能说明
- 创建新自定义决策
- 编辑现有自定义决策
- 支持添加/删除选项
- 支持设置选项权重（可选）
- 保存后自动返回上一页

### 路由参数
```typescript
{
  mode: 'create' | 'edit';  // 创建或编辑模式
  decisionId?: string;       // 编辑模式下的决策ID
}
```

### 功能流程
1. 输入决策名称
2. 添加选项（至少2个）
3. 可选：开启权重模式，为每个选项设置权重
4. 点击保存按钮

## 5. 历史页 (History Screen)

**文件路径**: `client/screens/history/index.tsx`

### 功能说明
- 展示所有决策历史记录（最多100条）
- 支持按分类筛选
- 支持按日期范围筛选（今天、7天、30天、全部）
- 支持搜索功能
- 支持置顶/取消置顶
- 支持删除单条记录（带撤销功能）
- 显示决策统计面板（总次数、分类分布、最近决策时间）

### 筛选功能
| 筛选类型 | 选项 |
|----------|------|
| 分类筛选 | 全部、饮食、生活日常、休闲娱乐、学习工作、聚会游戏 |
| 日期筛选 | 今天、7天、30天、全部 |

### 交互逻辑
| 操作 | 行为 |
|------|------|
| 点击置顶图标 | 切换置顶状态 |
| 左滑记录卡片 | 显示删除按钮 |
| 点击删除按钮 | 删除记录，显示3秒撤销提示 |
| 点击撤销 | 恢复已删除的记录 |

## 8. 设置页 (Settings Screen)

**文件路径**: `client/screens/settings/index.tsx`

### 功能说明
- 夜间模式切换
- 音效开关
- 触感反馈开关
- 震动开关
- 转盘配色方案选择（5种方案预览）
- 指针样式选择（4种样式预览）
- 清除所有数据

### 设置项列表
| 设置项 | 类型 | 说明 |
|--------|------|------|
| 夜间模式 | Switch | 切换深色/浅色主题 |
| 音效 | Switch | 转盘旋转时播放音效 |
| 触感反馈 | Switch | 转盘旋转时触感反馈 |
| 震动 | Switch | 转盘结束时震动 |
| 配色方案 | 选择器 | 5种配色方案 |
| 指针样式 | 选择器 | 4种指针样式 |
| 清除数据 | 按钮 | 清除所有本地数据 |

## 9. 我的决策页 (My Decisions Screen)

**文件路径**: `client/screens/my-decisions/index.tsx`

### 功能说明
- 展示所有自定义决策列表
- 支持搜索功能
- 支持按分类筛选
- 支持按日期筛选（日历点选）
- 支持置顶/取消置顶（长按弹出菜单）
- 支持删除（长按弹出菜单）
- 显示决策创建时间

### 筛选功能
| 筛选类型 | 选项 |
|----------|------|
| 分类筛选 | 全部、饮食、生活日常、休闲娱乐、学习工作、聚会游戏 |
| 日期筛选 | 日历点选（选择具体日期） |

### 交互逻辑
| 操作 | 行为 |
|------|------|
| 点击决策卡片 | 跳转决策页 |
| 长按决策卡片 | 弹出置顶/删除菜单 |
| 点击分类按钮 | 展开/收起分类标签 |
| 点击日历按钮 | 弹出日历选择器 |
| 点击搜索框 | 输入关键词搜索 |

### 置顶功能
- 长按决策卡片弹出操作菜单
- 菜单包含：置顶/取消置顶、删除
- 置顶的决策显示在列表顶部
- 置顶指示器：金色横线 + 金色星星图标
